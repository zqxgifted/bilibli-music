# 避坑清单

全部是真实项目（9000+ 条投稿、上千首歌）实战踩过的坑。

---

## 一、网络 / 风控

1. **412 / -352 / -799 是 per-mid 限流**，不是 IP 全封：同一时刻 A 号能抓、B 号不能。
   等 30–60 分钟，别连续重试。

2. **下载接口不受空间接口风控影响**：列表抓不到时，下载照样能跑。
   所以卡在抓取阶段时，先把已有的基底下完。

3. **`SESSDATA` 过期表现为 `nav` 返回 `-101`**（不是大量 412）。
   过期时下载接口**反而能通**，只是拿不到大会员音质。程序会自动检测并提示。

4. **并发别贪**：`download_jobs=4` 是实测稳定值，`RateLimiter 1.1/s` 别调高。

5. **`nav` 未登录时也返回 `wbi_img`** —— WBI 签名密钥不要求登录。
   只看 `code == 0` 会导致取不到签名密钥、空间接口全军覆没。

---

## 二、文件操作

6. **删除一律先 `os.rename` 到 `待删除\`**。同盘移动是元数据操作，0.2 秒完成 3000 个文件；
   直接删会被安全钩子按轮次限额拦、或被占用文件卡住。

7. **中文路径别走 PowerShell 的回收站钩子**（会 GBK 乱码 → fail-closed）；
   用 Python `os.remove` / `os.rename`。

8. **Windows 仅大小写重命名时**，`os.path.exists(新名)` 会把自己判成冲突 ——
   比较 `os.path.normcase()`，或用临时名中转。

9. **下载临时文件按线程复用**（`w<线程id>.m4s`，靠 `"wb"` 截断），**不做逐个删除**。
   逐个删会被安全钩子在第 50 个之后拦下来，既留一地垃圾又可能卡住工作线程。

10. **不能用 `Path.with_suffix`** —— 歌名里带英文点号（如「右肩の蝶(レンver.)」）
    会被当成扩展名吃掉。拼接完整路径字符串。

## 三、数据一致性

11. **基底不能「已存在就不更新」**：错收的条目会被永久保护。
    必须有**净化** + 允许新版本替换。

12. **改完基底要对账三方**：`基底条数 == 唯一键数 == 磁盘文件数`，差一个都要查。

13. **绝对不要 `exec(脚本头部)` 借函数**：会顺带执行写清单/写文档的语句，
    把基底冲成几条（真发生过，基底 json 从 1436 变成 3）。
    正确做法：`importlib.util.spec_from_file_location()` 加载模块，或用 `py_compile` 只验语法。

---

## 四、命名 / 判定

14. **黑名单只判分P名**（多P 歌回），单P 才判标题。用总标题判会把整场歌回误杀。

15. **归一化歌名时必须先去掉 emoji 和零宽字符**。
    少了这步，「❤️萌妹」和「❤萌妹」算成两首歌，去重时互相顶替，
    磁盘上就会多出一堆重复文件。

16. **前缀白名单/黑名单的关键词不要带【】**：`【粉丝团名】` 剥完符号是 `粉丝团名】xxx`，
    带括号反而匹配不到。

17. **`manual_key` 必须分P级**（`BVxxx_pN`）。BV 级会把同视频其他分P一起改键，
    一次误伤 3 首歌。

18. **文件名清洗顺序**：去 `【】` 标签 → 去 `#N` 系列号（正则 `#\d+(?=\s)`，
    保护 `心拍数#0822` 这种歌名）→ 去开头标点 → **保留结尾 `~` 等语气符**。

19. **`m4a` 内嵌 title 是 B 站原标题**，手机播放器优先读它，会出现
    「文件名干净、播放器里有【某某】前缀」的假象。下载时统一写：
    `title=纯歌名 / artist=UP / comment=B 站链接`。

20. **`--jobs` 并发下载时，清单文件名必须唯一**（`歌名_BV_pN`），
    否则两个同名不同版本会互相覆盖。

## 五、GUI（tkinter）

21. **ttk 页签尺寸跳变**：`clam` 主题下选中态自动加内边距。
    所有状态的 `padding` / `expand` 必须显式设成一样，选中态**不要加粗**。

22. **下拉框看起来是空的**：`clam` 主题下 `readonly + focus` 状态默认白底白字，
    必须显式覆盖 `foreground`。

23. **表格显示不全**：Treeview 默认按行数算「请求高度」，会撑大父容器。
    给个小的 `height`，配合父容器 `weight=1` 让它拉伸填满。

24. **勾选后重建整棵树会丢展开状态**。要么只更新那一行（推荐），
    要么重建前记住 `open` 状态、重建后恢复。

25. **删 UI 控件后要全局搜索控件名**，确认没有残留引用。
    删掉了状态标签但 `_set_running()` 还在引用它 → 抛 `AttributeError`
    → 任务根本没启动，界面表现是「状态瞬间变回空闲」。

26. **后台任务不要在子线程碰 UI**。tkinter 不是线程安全的：
    子线程只做耗时操作，结果通过 `queue` 传给主线程，主线程用 `after()` 轮询。

27. **测试 GUI 必须真的跑 mainloop**：涉及 `after()` 异步回调时，
    不跑 mainloop 会抛 `RuntimeError: main thread is not in main loop`。

28. **同一个容器里不能混用 pack 和 grid**：
    「cannot use geometry manager grid inside X which already has slaves managed by pack」。
    卡片标题行要放在**外层** frame 里（用 pack），内层保持无子控件状态给 grid 用。

## 六、打包

29. **中文路径下 spec 里的 `SPECPATH` 会被截断** —— 用环境变量传源码目录。

30. **.ps1 文件要存成 UTF-8 with BOM**，否则 PowerShell 按 GBK 读会中文乱码 + 语法错误。

31. **单文件 exe 双模式**：`xxx.exe` → GUI；`xxx.exe --run-py script.py` → 当解释器用。
    判断调用方是 exe 还是 python.exe 要**取文件名**，不要判断完整路径前缀。

32. **只构建一次，生成 lite/full 两个包**（每次 PyInstaller 要 3 分钟）。
